# Codeforces Solutions

A collection of **competitive programming solutions in C#** developed while solving Codeforces contests.

The repository organizes solutions by contest and keeps each problem as a separate source file for easy reference, practice, and review.

## Running a Solution

Clone the repository:

```bash id="g1j3cy"
git clone https://github.com/otabek-kholmirzaev/codeforces.git
cd codeforces
```

Individual `.cs` files can be copied into a standard competitive-programming environment and submitted directly to Codeforces.

For local execution with the .NET SDK:

```bash id="w4by9f"
dotnet new console -n Solution
cd Solution
```

Replace `Program.cs` with the desired solution and run:

```bash id="d6rj3z"
dotnet run
```
